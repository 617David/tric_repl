Trip Expense Splitter - Portable Windows Version
================================================

QUICK START:
-----------
1. Double-click "launch.vbs" (recommended - no console window)
   OR
   Double-click "launch.bat" (shows a brief console window)

2. The app will open in your default web browser

3. All your data is stored locally in your browser


ABOUT:
-----
Trip Expense Splitter is a local-first web application for splitting
trip expenses fairly among participants.

Features:
- Create multiple trips to organize expenses
- Add participants for each trip
- Record expenses with flexible splitting options
- Automatic settlement calculations showing who owes whom

SYSTEM REQUIREMENTS:
-------------------
- Windows 7 or later
- Any modern web browser (Chrome, Firefox, Edge, etc.)

DATA STORAGE:
------------
All data is stored in your browser's local storage.
- Your data stays private on your computer
- No internet connection needed after opening
- Clearing browser data will delete your trips

For more information, visit the project page or see the full README.md
